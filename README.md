# Alex's TV: downloads

This repo only holds the finished app file for Fire TV sticks. The code is private.

**Install on a stick:** in the Downloader app, open
`https://github.com/blentoo/alexs-tv-releases/releases/latest/download/AlexsTV.apk`

Sticks update themselves from here (Settings → Check for updates in the app).

`wallpapers/`: images here show up in the app's wallpaper picker. This repo is public, so use scenery and art, not personal photos.
